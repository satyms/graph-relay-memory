Shared Graph Memory for AI Agent Teams

When autonomous agents collaborate on an incident, flat context buffers fail: agents forget history, collide on uncoordinated tasks, and repeat failed runbooks. Relay equips agent teams with typed episodic timelines, bi-temporal fact lineage, self-healing procedural runbooks, and atomic coordination leases.

Measured on dev machine (Intel Core Ultra 5): 20 agents racing for 10 tasks, 0 duplicate claims, 1,914 operations/sec, and 94 automated tests passing.
Launch Studio Incident Workflow System Architecture
Agents Forget
Flat chat buffers and vector stores truncate history. Relay tracks episodic event streams and non-destructive SUPERSEDES fact lineage.
Agents Collide
Independent agents lack atomic locks, racing to claim tasks. Relay enforces single-Cypher atomic Compare-And-Set (CAS) claims with leased recovery.
Agents Repeat Mistakes
Agents blindly retry static runbooks. Relay automatically forks failed procedures into new versions with learned preconditions.

Graph Data Model & Cypher Engine

Everything is a typed node or edge in FalkorDB. Five memory layers provide specialized storage, while parameterized Cypher guarantees high-throughput atomicity.

Episodic: Session • Event Semantic: Fact (SUPERSEDES • valid_from/to) Procedural: Procedure • Preconditions • Laplace Ranking Coordination: Task • Lease • Handoff • Approval Insight: PageRank • Blast Radius • Provenance 
// 1. Atomic Compare-And-Set Task Claim (server/app/queries/coordination.py)
MATCH (t:Task {id: $task_id})
WHERE t.status = 'open' AND (t.claimed_by IS NULL OR t.lease_expires_at < $now)
SET t.status = 'in_progress',
    t.claimed_by = $agent_id,
    t.lease_expires_at = $now + $ttl_ms,
    t.version = t.version + 1
RETURN t.id, t.claimed_by, t.version, t.lease_expires_at
