System Design

Engine Architecture

Relay decouples agent intelligence from durable state. Agents communicate via standard MCP tool calls; FalkorDB enforces multi-tenant boundaries and graph concurrency. Click any component for implementation details.

1. Agent Swarm agents/base.py
Autonomous specialized roles: Triage, Investigator, Remediator, Comms. Driven by LLM tool-calling loop over MCP protocol.
2. Model Adapter agents/llm_adapter.py
Configurable `MODEL_PROVIDER`: supports local OpenVINO model for offline edge inference or cloud LLMs.
3. MCP Memory Server server/app/main.py
Exposes episodic, semantic, procedural, and coordination tool surfaces. Validates tenant tokens and enforces role gates.
4. Tool Layer server/app/tools/
Parameterized handlers mapping tool inputs to validated Cypher queries. Guaranteed zero user-supplied Cypher injection.
5. FalkorDB Core server/app/graph.py
Graph-per-tenant physical separation (`tenant_acme`, `tenant_globex`), plus global read-only `shared_runbooks`.
6. Lease Reaper server/app/reaper.py
Background daemon sweeping expired task claims. Re-opens abandoned work so surviving agents auto-reclaim it.
7. Consolidation server/app/consolidation.py
Extracts recurring episodic observations into consolidated semantic facts; decays confidence of unreinforced facts.
8. SSE Telemetry Stream /admin/stream
Server-Sent Events broadcasting graph mutations, task claims, lease countdowns, and approvals live to connected dashboards.

FalkorDB Schema

Graph Data Model & Cypher Engine

Everything is a node or edge in FalkorDB. Typed labels eliminate schema fragmentation, while parameterized Cypher guarantees high-throughput atomicity.

Topology: Entity (Service, Host) Coordination: Incident, Task, Hypothesis, Handoff, Approval Procedural: Procedure, Step, Outcome Semantic: Fact (SUPERSEDES, valid_from/to) Episodic: Session, Event (observation, action, decision) 
// 1. Atomic Compare-And-Set Task Claim (server/app/queries/coordination.py)
MATCH (t:Task {id: $task_id})
WHERE t.status = 'open' AND (t.claimed_by IS NULL OR t.lease_expires_at < $now)
SET t.status = 'in_progress',
    t.claimed_by = $agent_id,
    t.lease_expires_at = $now + $ttl_ms,
    t.version = t.version + 1
RETURN t.id, t.claimed_by, t.version, t.lease_expires_at
